🎵 Moonbeat
Moonbeat is a retro-inspired browser rhythm game built with HTML, CSS, and JavaScript.

Players use the A, S, D, and F keys to hit falling notes and earn points as they travel down four lanes. Inspired by classic rhythm and arcade games, Moonbeat combines simple controls with fast-paced gameplay to create an engaging reaction-based challenge.

Features
🎹 Four-lane rhythm gameplay
🎯 Score tracking system
⚡ Real-time keyboard controls
🎵 Falling note mechanics
🌙 Clean retro-inspired design
💻 Runs entirely in the browser
Controls
Key	Lane
A	Lane 1
S	Lane 2
D	Lane 3
F	Lane 4
How to Run
Online
Open the live demo in your browser.

Local
Download or clone the repository.
Open index.html in any modern web browser.
Start playing.
